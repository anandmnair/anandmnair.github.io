**Java · Axon Framework · Event Sourcing**

Event sourcing was new, unfamiliar territory for most of the team when this
was built. This POC modelled a workflow on Axon to make the concept concrete
enough to explain — not slides, a running example. It did its job: the POC
secured buy-in for a real project, which later continued in another,
internal repository.
