**Kotlin · Generic Feedback Collection**

POC for collecting user feedback from any application through one shared,
generic endpoint, rather than each application building its own feedback
form and storage. It didn't go past the POC stage — a similar capability was
already in the pipeline elsewhere and shipped a few months later with a
slightly different approach, so this one stopped here.

[Repository](https://github.com/anandmnair/feedback-api)
