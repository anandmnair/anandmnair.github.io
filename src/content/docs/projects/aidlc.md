**Agentic AI · TDD · Multi-tool Pipeline**

"One big prompt" development produces unreviewable output, hallucinated
requirements, and untested code. AIDLC replaces it with a disciplined agentic
AI pipeline: seven specialist AI agents — curator, analyst, architect,
developer, tester, documenter, reviewer — each with a narrow responsibility,
explicit inputs and outputs, and guardrails with acceptance criteria.

No phase boundary is crossed without explicit human approval. Sixteen
mandatory guidelines run underneath every agent: never assume or hallucinate,
test-first always, hexagonal architecture, coverage and mutation gates at
95%, and a status footer on every response. One installer converts the
tool-agnostic core into the native format for Claude Code, GitHub Copilot,
Cursor, Gemini CLI, Windsurf, and JetBrains IDEs.
