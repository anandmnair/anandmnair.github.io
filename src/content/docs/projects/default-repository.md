**Java · Spring Batch · Microservices · BDD**

The catch-all repository from early on: several POCs living side by side
rather than split into their own repos — Spring Batch jobs, a web front end
for triggering them, microservices behind a service registry, a web service,
an API gateway, and BDD scenarios with Cucumber. Less a single project than
a record of what was being explored at the time.
