**Java · Spring Cloud · Eureka**

One of the first microservices attempts on a team that had never worked with
a service registry, an API gateway, or internal service-to-service calls
before. This POC broke a Swing-based monolith apart and put the pieces back
together as microservices behind Eureka — service registry, multiple
replicas, load balancing, and routing through an API gateway. All new ground
for the team at the time.
