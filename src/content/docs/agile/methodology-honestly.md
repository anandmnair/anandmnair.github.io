Scrum, Kanban, SAFe, XP — these are frameworks for organising work. They are not
agility, and adopting one does not produce it. Plenty of organisations run every
ceremony faithfully and deliver in the same annual increments as before, because
the ceremonies were adopted and the feedback loop was not.

**The single test:** when did feedback from someone who actually uses the system
last change what you were about to build? If there is no recent answer, the
methodology is decoration.

What genuinely differentiates:

| Present | Absent |
|---|---|
| Working software in front of users regularly | Demos to internal stakeholders only |
| Scope adjusts as you learn | Scope fixed at planning, learning discarded |
| The team decides how | The team is told how |
| Retrospectives change something | Retrospectives produce a list |
| Done means released | Done means dev-complete |
