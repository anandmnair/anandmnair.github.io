Where agents have genuinely earned their place:

- **Knowledge extraction from legacy code.** Ingest a repository, build a
  queryable graph, answer questions grounded in the source with citations. The
  citation requirement is what separates this from a plausible-sounding guess.
- **Document-heavy workflows.** Trade finance, claims, onboarding — anywhere the
  input is a bundle of semi-structured documents and the output is a set of
  fields plus a decision.
- **Migration tooling.** Deriving transformation rules from data rather than
  waiting for a business analyst to hand-write them.
- **Test generation.** Especially characterisation tests around legacy code you
  are about to change.

Where they have not:

- Anything where being wrong is silent and expensive.
- Anything you cannot verify more cheaply than doing it yourself.

That second point is the whole test. **If checking the agent's work costs more
than doing the work, the agent is a liability.**
