---
title: 'Habits worth keeping'
description: >-
  Commit small, run the tests before reading the code, keep a human-written core for the
  hardest domain decisions, and notice the moment you have stopped actually reading what
  the model wrote.
order: 5
cardBadges: ['Code Review', 'Small Commits']
---

- **Commit small.** Generated changes are easy to make large. Resist.
- **Run the test suite before you read the code.** It is faster.
- **Keep a human-written core.** The parts of the system that encode the hardest
  domain decisions deserve a human author, if only so someone understands them
  under pressure.
- **Notice when you have stopped reading.** The failure mode of AI-assisted
  development is not bad code. It is accepted code nobody has read.
