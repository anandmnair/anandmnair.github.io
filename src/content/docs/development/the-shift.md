Writing code used to be the slow part. It is not any more. The slow parts now
are **deciding what to build**, **describing it precisely enough**, and
**verifying what came back**.

That inverts a habit. Time that went into typing should now go into the
specification and the tests — which is, awkwardly, exactly what
[TDD](/craftsmanship/test-driven-development/) and
[design-first](/craftsmanship/design-first-approach/) always asked for. AI did
not create those disciplines. It removed the excuse for skipping them.
