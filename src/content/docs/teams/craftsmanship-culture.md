Culture is what happens when nobody is watching, and it is set by what gets
rewarded rather than what gets stated.

Practices that build it:

- **Make quality visible.** Mutation scores, architecture rule violations,
  contract failures. Visible metrics move; invisible ones do not.
- **Ship shared libraries.** A library a hundred services depend on spreads a
  standard more effectively than any document, because using it is easier than
  not.
- **Reward the unglamorous.** The engineer who deleted 4,000 lines and improved
  the failure mode did more than the one who shipped a feature. If only one of
  them gets recognised, you have told everyone what matters.
- **Mentoring as an expectation, not a favour.** Seniority means raising the
  people around you, and it should be assessed that way.
- **Hackathons and internal talks** — genuine ones, where the output can be
  adopted. They surface capability that day-to-day work never reveals.
